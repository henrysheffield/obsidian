# Addition Rule

$$ P(A ~or~ B) = P(A \cup B) = P(A) + P(B) - P(A \cap B) $$
Where A or B is the [[Union]]

- Note: you must subtract the [[Intersection]] to avoid double counting values

## Important Case

- Being mutually exclusive changes the addition rule
