# Collectively Exhaustive

## Notes

- The sum of all possible groups covers all possible options.
- Different from [[Mutually Exclusive]] which is that a number of events are completely distinct and there is no overlap between groups
## Examples / Problems

- A venn diagram where $A \cup B=1$ and the outside = 0
- Union covers entire sample space
$$A \cup B = S$$
where $S$ is same space
