# Eisenhower Matrix

## Notes

Every morning, divide tasks into 4 categories

1. Musts
2. Shoulds
3. Nice to haves
4. Wont’s

You must perform the Musts first then Shoulds → Nice to haves → Wonts

Example:

1. Practice essay + anki
2. Obsidian note reviews
3. Clean room / Read book
4. Procrastinate
