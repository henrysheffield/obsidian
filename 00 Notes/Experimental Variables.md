# Experimental Variables

## Notes

| Variable         | Description                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------------- |
| Independent (IV) | The variable you **change** e.g. amount of water given to plant                                         |
| Dependent (DV)   | The variable you **observe/measure** e.g. the height growth DUE to the independent variable             |
| Control          | Variables that you keep **constant** to ensure a fair and reliable experiment (e.g. amount of sunlight) |
