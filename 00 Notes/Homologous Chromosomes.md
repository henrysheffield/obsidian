# Homologous Chromosomes

## Notes

Matching pairs of chromosomes in a diploid organism (containing two sets of chromosomes).

They are almost identical but not quite:

- Same centromere location
- Same gene sequence (same order)
- Same size

But, can contain different [[Alleles|alleles]] of the same gene sequence (meaning different observable characteristics)
