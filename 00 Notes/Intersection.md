# Intersection

**Summary:** Both a and B in a set. $$ A \cap B $$

---
## Description

Represents both A and B in a set

## Flashcards

What does the symbol look like for intersection? :: It is a frowny face because it gets the smallest part of the Venn diagram ($A\cap B$)
<!--SR:!2026-07-19,65,310-->

Describe what the intersection is in probability? :: It is the middle part of the Venn Diagram, representing the intersection of values of A and B e.g. $$ A = {1,2,3}\quad B={2,3,4} $$ The intersection would be ${2,3}$ as those are the values that are shared between A and B. Represented by $A \cap B$
