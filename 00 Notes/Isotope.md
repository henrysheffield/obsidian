## Isotopes

### Description

An **isotope** is a variant of a particular chemical element. While the atoms of an isotope share the same number of **protons** (atomic number), they differ in the number of **neutrons** within the nucleus. This results in a different atomic mass while maintaining the same chemical properties.

### Structural Differences

- **Atomic Number ($Z$):** Identical (defines the element).
    
- **Mass Number ($A$):** Different (protons + neutrons).

### Comparison Example: Carbon

The element Carbon always has **6 protons**, but its isotopes vary by neutron count:

|**Isotope**|**Protons**|**Neutrons**|**Mass Number**|
|---|---|---|---|
|**Carbon-12**|6|6|12|
|**Carbon-14**|6|8|14|
