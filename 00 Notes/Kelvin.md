# Kelvin

## Notes

Absolute temperature, default in SI Units. All positive values.

- Absolute lowest value of temperature = $0 K$ (or $-273.15^{\circ} C$

![[Kelvin-1780189954237.webp]]
*Equivalent temperatures of Kelvin*

## Converting

Kelvin → Celsius
$-237.15$
e.g. $1 K = 1 - 273.15 = -272.15^{\circ}C$

Celsius → Kelvin
$+237.15$
e.g. $100^{\circ}C = 273.15 + 100 = 373.15 K$
