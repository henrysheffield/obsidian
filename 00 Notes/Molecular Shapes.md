# Molecular Shapes

## Notes

![](https://www.youtube.com/watch?v=DBrq31w8vC4)

![[Molecular Shapes-1782610018992.webp]]
*Common shapes*

### Linear

Angle is $180^\circ$

Example: Carbon Dioxide

### Trigonal Planar

Angle is $120^\circ$ (find by dividing $360$ by $3$)

Example: $BH_{3}$ or $COCl_{2}$ 

Note: elements tend to be in group 3

### Tetrahedral

Angle is $109.5^\circ$ - Note this represents a 3D model, not a 2D perfect circle
Example: $CH_{4}$ 

### Trigonal Pyrimidal

Angle is $107^\circ$

Contains a lone pair of electrons

Example: $NH_3$ or $PH_3$

Note: elements tend to be in group 5

### Bent

Example: $H_{2}O$ with an angle of $104.5^\circ$
