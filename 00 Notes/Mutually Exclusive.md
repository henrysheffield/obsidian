# Mutually Exclusive

## Summary

Mutually Exclusive (or disjoint) occurs when 2 or more events (e.g. A and B) cannot occur at the same time. e.g. Turning left and right at an intersection is impossible. Addition Rule changes to $P(A or B) = P(A) + P(B)$

---
## Description

2 or more events that cannot occur at the same time. If one occurs, the other event is automatically impossible.
## Example

- Turning left *and* right at an intersection *at the same time* is obviously impossible
![[Mutually Exclusive-1775435518671.webp|395]]

- In a Venn Diagram, the circles do not touch as there is no overlap in A and B.

## Equation:

$$ P(A \cup B) = P(A) + P(B)  $$
The equation shows that the [[Union]] of A and B is simply their values combined because there is no [[Intersection]] between them

$$ P(A \cap B) = 0 $$
Simple expression as you can see that there are no values in the intersection of A and B
