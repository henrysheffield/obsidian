# Naming Acids

## Notes

| **Anion Ending**            | **Prefix** | **Suffix**  | **Example Anion**  | **Example Acid Formula** | **Example Acid Name** |
| --------------------------- | ---------- | ----------- | ------------------ | ------------------------ | --------------------- |
| **-ide** (Binary/No Oxygen) | `hydro-`   | `-ic` acid  | Chloride ($Cl^-$)  | $HCl$                    | Hydrochloric acid     |
| **-ate** (Oxyacid)          | _None_     | `-ic` acid  | Nitrate ($NO_3^-$) | $HNO_3$                  | Nitric acid           |
| **-ite** (Oxyacid)          | _None_     | `-ous` acid | Nitrite ($NO_2^-$) | $HNO_2$                  | Nitrous acid          |
|                             |            |             |                    |                          |                       |
## Examples / Problems

Name $H_{2}S$? :: Hydrosulfuric acid (-ide → hydro- … -ic)

Name $HClO_{2}$ (note $ClO_{2}$ is called Chlorite)? :: Chlorous acid (ite → -ous)
<!--SR:!2026-06-30,17,330-->
Formula for *Hydrocyanic acid*? :: Cyanide = $CN^{-}$ → $HCN$
<!--SR:!2026-07-01,18,324-->
Formula for Carbonic Acid? :: $H_{2}CO_{3}$
<!--SR:!2026-06-29,16,330-->

<!--SR:!2026-06-30,17,330-->

<!--SR:!2026-06-30,17,330-->
