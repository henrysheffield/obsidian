C'est une excellente question ! Ce que tu décris s'appelle des **Callouts** (ou encadrés de texte). C'est un outil puissant dans Obsidian pour structurer tes notes et les rendre visuellement attrayantes.

Voici comment les utiliser et à quoi ils ressemblent.

---

## 1. Comment utiliser les Callouts `> [!]`

La syntaxe de base consiste à commencer une ligne par un signe "supérieur à" (`>`), suivi d'un crochet contenant un point d'exclamation et le type de callout.

### Syntaxe standard

Markdown

```
> [!TYPE] Titre (Optionnel)
> Contenu de l'encadré.
```

### Les types les plus courants et leur apparence

Chaque type possède une couleur et une icône spécifique dans Obsidian :

- **`> [!INFO]`** (Bleu) : Pour des informations générales ou des compléments.
    
- **`> [!SUCCESS]`** (Vert) : Pour des points positifs, des conclusions ou des étapes réussies.
    
- **`> [!WARNING]`** (Orange) : Pour attirer l'attention sur un point de vigilance.
    
- **`> [!DANGER]`** (Rouge) : Pour des erreurs critiques ou des choses à ne surtout pas faire.
    
- **`> [!TIP]`** (Cyan) : Pour des astuces, des conseils ou des idées lumineuses.
    
- **`> [!QUOTE]`** (Gris) : Pour mettre en avant une citation.
    

### Astuce : Rendre un Callout repliable

Si tu as beaucoup de texte, tu peux ajouter un signe `+` ou `-` juste après le type pour que l'encadré puisse se réduire :

- `> [!INFO]+` : L'encadré est **ouvert** par défaut mais peut être fermé.
    
- `> [!INFO]-` : L'encadré est **fermé** par défaut.

## 2. Raccourcis clavier utiles pour le texte

Obsidian utilise des raccourcis standards, mais certains sont spécifiques à la prise de notes :

### Formatage de base

- **Surligner du texte** : Il n'y a pas de raccourci par défaut pour le surlignage (`==texte==`), mais tu peux en configurer un dans `Paramètres` > `Raccourcis clavier` en cherchant "Surligner".
    
- **Gras** : `Ctrl` + `B` (ou `Cmd` + `B` sur Mac).
    
- **Italique** : `Ctrl` + `I` (ou `Cmd` + `I`).
    
- **Ajouter un lien interne** : `[[` (Tape deux crochets ouvrants).
    
- **Transformer en liste à puces** : `Ctrl` + `Maj` + `8` (sur Windows).
    

### Navigation et édition

- **Recherche globale** : `Ctrl` + `Maj` + `F`.
    
- **Ouvrir la palette de commandes** : `Ctrl` + `P` (C'est le raccourci le plus utile pour trouver toutes les fonctions d'Obsidian).
    
- **Basculer entre Mode Édition et Lecture** : `Ctrl` + `E`.
    

### Astuce de pro : Multi-curseurs

Si tu veux modifier plusieurs lignes en même temps, maintiens `Alt` et clique à différents endroits avec ta souris.
