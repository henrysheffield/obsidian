# Open, Closed and Isolated System

| System   | Description                                              |
| -------- | -------------------------------------------------------- |
| Open     | System that can freely exchange **both energy and mass** |
| Closed   | Can only exchange **energy**, mass is constant           |
| Isolated | Perfectly sealed, neither losing **energy or mass**      |
|          |                                                          |

![[Open, Closed and Isolated System-1779937450151.webp]]
*Diagram of 3 types of systems*

- An open tube can exchange both mass and energy (e.g. evaporation losing mass and changes temperature)
- A closed tube has a constant mass but still can transfer energy (e.g. you hold the tube)
- An isolated system is where energy and mass is constant
