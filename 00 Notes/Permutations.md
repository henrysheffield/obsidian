# Permutation

**Summary:** Number of ways to arrange something where order matters.

---
## Description

Calculates number of ways to arrange something **where order matters**. For example, a permutation sees a difference between $A,B,C \quad B,A,C$ but a combination would not.

## Key Ideas

- Order matters
- Often used in problems like *How many ways to arrange a line of people for a photo (the order matters of the people)*

## Formula

$$ P(n,r)=\frac{n!}{(n-r)!}$$

*where*
$n$ = Total number of items in a set
$r$ = Number of items being chosen / arranges
$!$ = Factorial (e.g. $3!=3 \times 2 \times 1$)
