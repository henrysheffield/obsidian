# Prokaryotic

## Notes

Any cell which lacks:

1. A well defined nucleus
2. Membrane bound [[Organelle|organelles]]

This difference distinguishes prokaryotic cells to [[Eukaryotic]] 

Important: Prokaryotic cells still contain [[Genetics|genetic]] material, however it floats around the cytoplasm.

[[Bacteria]] is a great example of a prokaryotic cell
