# RNA vs DNA

## Notes

| DNA                                                                    | RNA                                                                      |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Deoxyribonucleic acid                                                  | Ribonucleic acid                                                         |
| Contains a phosphate group, sugar (deoxyribose) and a nitrogenous base | Contains a phosphate group, sugar (with hydroxyl) and a nitrogenous base |
| Adenine, Guanine, Thymine and Cytosine                                 | Adenine, Guanine, **Urecil** and Cytosine                                |
| Double stranded                                                        | Single stranded                                                          |
|                                                                        |                                                                          |
