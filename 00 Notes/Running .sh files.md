# Running .sh files

## Notes

### 1. Allow the file to be executable

`chmod +x "file name"

### 2. Run the file using sudo

`sudo ./"file name"`

### Optional: Rename the file

`mv "file name" "new file name"

> [!TIP]
> Brackets only required for names with spaces, brackets or other characters
