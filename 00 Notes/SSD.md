# SSD 

## Notes

- Faster, more durable than a hard drive
- Can be used solely instead of a hard drive
- Great at storing data, but is slower than [[RAM]]
- Measured in `MB/s` where the higher this ‘read’ value is, the faster the SSD can transfer and read data
