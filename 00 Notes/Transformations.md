# Transformations 

## Notes

$$y = a \times f(b(x-h))+k$$

| Part | Affects            | Logic                                          |
| ---- | ------------------ | ---------------------------------------------- |
| k    | Vertical Shift     | + = up, - = down                               |
| a    | Vertical Stretch   | > 1 = Stretch < 1 = Compression                |
| h    | Horizontal Shift   | + = left, - = right (counter-intuitive)        |
| b    | Horizontal Stretch | Multiplier of 2 = ½ shrink (counter-intuitive) |

### Order (SRT)

1. Stretch (vertical (a), horizontal (b))
2. Reflect (in y or x axis)
3. Translate (vertically (k), horizontally (h))

### Useful table

|**Transformation**|**Algebra**|**Effect on Graph**|
|---|---|---|
|**Vertical Shift**|$f(x) \pm k$|Up ($+$) or Down ($-$)|
|**Horizontal Shift**|$f(x \pm h)$|**Left ($+$) or Right ($-$)**|
|**Vertical Stretch**|$a \cdot f(x)$|Taller ($a>1$) or Shorter ($a<1$)|
|**Horizontal Stretch**|$f(b \cdot x)$|**Narrower ($b>1$) or Wider ($b<1$)**|
|**Reflect x-axis**|$-f(x)$|Upside down|
